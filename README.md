# Thodu

Keyboard hints for everything on an Omarchy screen: Homerow for Omarchy

- [SEED.md](SEED.md): purpose, principles, decisions and evidence.
- [SPEC.md](SPEC.md): the contract the code is built against.
- [AGENTS.md](AGENTS.md): how agents take and finish work; [tasks/](tasks/) holds the work.
- `tools/gate`: the gate every change passes. `tools/agent-loop`: runs a build agent in its own worktree. `tools/land`: lands a branch.

Requirements: git, Python 3 and bubblewrap, rustup, Qt 6 and Omarchy.
